## Agent skills

### Issue tracker

Issues são trackeadas via GitHub Issues neste repo (github.com/henrilhos/compasso), usando a CLI `gh`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Usa os cinco labels canônicos como estão (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Ver `docs/agents/triage-labels.md`.

### Domain docs

Layout single-context: um `CONTEXT.md` + `docs/adr/` na raiz do repo. Ver `docs/agents/domain.md`.
